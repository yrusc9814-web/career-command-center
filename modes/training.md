# Mode: training — 培训 / 课程 / 认证评估

候选人问某个课程/证书值不值得学时，按 6 个维度评估：

| 维度 | 评估什么 |
|------|---------|
| 目标岗位对齐度 | 拉近还是拉远采购序列目标（执行采购 / 寻源开发 / 品类采购）？ |
| HR / 面试官信号 | 写在简历上 hiring manager 怎么看？ |
| 时间和精力 | 周数 × 每周小时 |
| 机会成本 | 这段时间不能做什么（用来看 JD / 面试 / 补真实成果）？ |
| 风险 | 内容过时？证书品牌弱？太基础（如只讲"什么是采购"）？ |
| 可展示产出 | 能不能沉淀一份可讲述的成果（品类降本方案 / 供应商开发复盘 / 数据分析作品）？ |

## 推荐结论

- **学** → 4-12 周计划，每周交付 + scoreboard
- **不学** → 给一个更好的替代方案 + 理由
- **限时学（最多 X 周）** → 浓缩计划，只保留最关键部分

## 优先级（采购能力方向）

国内市场上能加分的方向（按当前短板选，**优先级永远低于真实经历和量化成果**）：

**品类与成本：**
1. 品类管理实战（品类策略 / Spend 分析 / Should-cost 成本拆解，结合自己在管品类做一遍）
2. 成本工程基础（成本结构分析 / 价格拆解 / TCO 总拥有成本）
3. Excel 数据分析进阶（透视表 / Power Query — 采购数据复盘的日常工具）

**供应商与谈判：**
4. 商务谈判实战课（谈判准备表 / BATNA / 让步设计，配真实谈判复盘）
5. 供应商全生命周期管理（开发导入 → 绩效考核 → 淘汰退出）

**供应链与交付：**
6. 供应链管理基础（库存策略 / 安全库存 / Lead Time 结构）
7. 生产计划与物料基础概念（懂 PMC 语言，跨部门沟通不被动 — 但**不转岗 PMC**）

**数字化与外贸：**
8. ERP·SRM 采购模块实操（主流 ERP 的采购 / 库存 / 应付流程走通一遍）
9. 外贸实务（Incoterms、报关清关、信用证 / 国际物流基础 — 面向国际采购岗）

## 国内常见付费课程的避坑

- **培训机构包装的"采购总监速成班 / 高管研修班"** → 名头大于内容，HR 一眼能看出没有岗位支撑；职级靠经历不靠证书
- **"CPPM / 注册采购师"类国内认证** → 少数外企 / 国企认可，多数制造 / 贸易 / 零售企业招聘基本不看，不要为它付高价
- **泛泛的"供应链管理"大课** → 除非能结合自己的品类做产出，否则听完留不下可讲述的东西
- **Coursera / Udemy / B 站免费课** → 重要的是产出物，不是证书。**做出一份结合真实工作的成果（品类降本方案 / 供应商开发复盘 / 谈判案例库）比拿一张证书有价值 10 倍**

**总原则：能拿出一段真实可验证的采购成果（带量化数字 + 复盘文档 + 可在面试里讲 5 分钟）的"学习"，永远比拿一个证书有价值。证书只做锦上添花，不做主证据。**
