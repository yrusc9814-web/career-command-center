# Mode: project — 采购专项成果评估

评估候选人想做的一个"可展示成果"（品类降本专项 / 供应商开发复盘 / 数字化采购方案等）。6 维度打分（1-5）：

| 维度 | 权重 | 5 = ... | 1 = ... |
|------|------|---------|---------|
| 对目标岗位的信号 | 25% | 直接演示 JD 要的采购能力（寻源 / 谈判 / 降本 / 品类） | 与目标岗位无关 |
| 独特性 | 20% | 有自己的品类视角和取舍 | 网上模板套用、人云亦云 |
| 可展示性 | 20% | 有完整复盘文档 / 数据图表，5 分钟能讲清楚 | 只有零散记录，讲不出结构 |
| 量化指标潜力 | 15% | 有清晰指标（降本比例 X% / 供应商数量 N / OTD / 账期改善） | 没有可量化结果 |
| 投入时间 | 10% | 1-2 周可完成 | 3 个月以上 |
| STAR 故事潜力 | 10% | 有丰富的 trade-off 可讲（选型 / 让步 / 风险取舍） | 只是流程罗列 |

## "Interview Pack" 要求

每个被认可的专项都要有：
1. **One-pager**：业务背景 + 我的角色 + 关键动作 + 量化结果（一页纸）
2. **证据包**：可展示的支撑材料（数据截图、比价表结构、复盘文档 — **脱敏，不含真实供应商报价与合同信息**）
3. **复盘（Postmortem）**：什么 work，什么不 work，重来一次会怎么改

**国内特有的：**
- 最好有一篇 **知乎专栏 / 行业公众号文章**（脱敏后）写这个专项 — 国内 HR / 面试官会搜
- 面试里能白板画出"品类结构图 / 供应商矩阵 / 成本拆解表"是强信号
- 注意保密红线：涉及真实供应商、价格、合同金额的内容**永远不进公开渠道**

## 80/20 计划

- **第 1 周** → 框架 + 数据整理，跑通核心指标（降本拆解 / 供应商矩阵）
- **第 2 周** → 打磨 + 写 one-pager + 做证据包 + 写复盘

## 推荐结论

- **做** → 给周计划 + 每周 milestone
- **不做** → 解释为什么 + 有什么更好的替代
- **改方向到 [替代]** → 给出更高 ROI 的变体

## 适合 采购序列 的专项方向

**品类降本专项：** 选一个自己在管的品类（脱敏），做完整的 Spend 分析 → 成本拆解 → 降本路径（议价 / 替代导入 / 需求优化）→ 结果与复盘，写出降本比例 X% 的构成。

**供应商开发 0→1 复盘：** 完整还原一次新供应商开发（寻源 → 验厂 → 打样 → 小批 → 批产导入），写清筛选标准和每轮取舍，沉淀可复用的开发流程。

**供应商绩效与组合优化：** 给在管供应商建绩效考核维度（OTD / 质量 / 价格 / 配合度）与淘汰退出机制，展示供应商结构优化前后对比。

**库存与交付优化：** 针对一个物料族做安全库存 / MOQ / Lead Time 优化方案，量化库存下降与缺货率改善。

**ERP·SRM 数字化采购：** 复盘一次采购流程线上化（订单 / 对账 / 供应商主数据），量化效率提升（单据流转时间从 X 到 Y）。

**关键原则：**
1. **基于真实经历** > 凭空造方案（面试官三个追问就穿帮）
2. **有量化数据** > 只有方法论
3. **有取舍与复盘** > 一次性成功叙事
4. **能 5 分钟讲清楚** > 需要 30 分钟才能讲明白
5. **脱敏合规** > 细节堆砌（真实价格 / 供应商名 / 合同金额绝不外泄）
