### Tier D 触发关键词（JD 出现任一即 SKIP）

- 职责主体为 SQE / 质量序列（来料检验、8D、QSA 审核为主体，采购只是挂名）
- 职责主体为仓储物流（收发货、库存管理、运输调度为主体）
- 职责主体为生产计划（PMC、排产、物控为主体）
- 纯销售岗（供应商侧销售，不是采购职能）
- 派遣 / 外包 / 劳务外包关键词，或"采购外包驻厂"类岗位
- 职级严重倒退且职责不对等（如现任主管 → 专员档且不带品类）

## 评估流程（每个 JD 进 Block A 之前必须执行）

1. **真实门槛硬筛**：JD 命中任何 Tier D 触发关键词 → SKIP，不进 A-F
2. **公司归类**：对照本文档 Tier A/B/C 公司清单 + WebSearch 该公司画像
3. **画像反推**：评估"这家公司会不会真的给候选人面试机会"，不是"JD 写的能力候选人有没有"
4. **写入 report 头**：
   ```markdown
   **Tier:** A1 / A2 / A3 / B1 / B2 / B3 / C1 / C2 / C3 / D / 未明确
   ```
5. Tier A/B → 进 Block A-F 全评估
6. Tier C → 给"延后投递"建议
7. Tier D → SKIP，写一句"不在真实可达池"理由
