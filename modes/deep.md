# Mode: deep — 公司深度调研 Prompt（中国大陆版）

为目标公司生成一份结构化的调研 prompt，可以喂给 Claude / ChatGPT / Perplexity / Kimi 跑。**所有数据源都换成中国大陆可用的源。**

```
## 深度调研：[公司] — [岗位]

背景：我在评估 [公司] 的 [岗位]。需要可执行的信息来准备面试和谈判。请从下面 7 个维度回答，每个维度都给出来源链接。

### 1. 业务与供应战略
- 公司的核心业务是什么？营收/规模大概什么量级？自有产能还是贴牌/贸易为主？
- 品类结构：主要采购什么（生产物料 / 非生产物料 / 设备 / 包材 / 物流服务）？年采购额大概什么量级？
- 供应体系：供应商集中在哪些区域？头部供应商占比大概多少？有没有单一来源风险？
- 数字化水平：用什么 ERP？有没有 SRM / 采购平台？采购流程线上化程度？
- 最近有没有公开的建厂 / 扩产 / 出海 / 供应链转移动作？

**建议源：**
- 公司官网 / 公众号 / 招股书 / 年报（上市公司）
- 行业媒体与展会报道（行业展会名单、新品发布）
- 天眼查 / 企查查 — 分支机构、招投标记录、供应商关联
- 知乎 / 行业公众号 — 公司供应链与品类的讨论

### 2. 近 6 个月动态
- 最近的融资 / 上市 / 业务调整 / 新基地投产？
- 关键人事变动（采购总监 / 供应链负责人 / 事业部负责人）？
- 是在扩招还是在优化？目标团队是 +1 还是替补离职坑？
- 有没有出过供应中断 / 质量事故 / 法律风险 / PR 危机？

**建议源：**
- **脉脉职言区** — 搜公司名，看近 30 天的匿名讨论。**这是国内最快得到真实情况的源。**
- 36 氪 / 虎嗅 / 钛媒体 — 公司新闻
- 天眼查 / 企查查 — 工商变动、融资历史、关联公司
- 行业协会 / 招投标公告平台 — 中标与采购动态

### 3. 工作强度与作息
- **工时强度**：大小周？单休？旺季加班常态吗？
- 加班是默认还是看项目？出差 / 驻厂频率？
- 远程友好度？请假难度？
- 办公地点在园区还是厂区？通勤条件？

**建议源（关键）：**
- **看准网（kanzhun.com/{公司}）** — 国内最全的口碑站，看 总评分 + 工作时间 + 加班 + 工作环境
- **脉脉职言** — 搜 "公司名 加班" / "公司名 工作强度" / "公司名 出差"
- **知乎** — "如何评价 {公司} 的工作强度"
- **小红书** — 搜 "{公司} 上班"，会有真实日常分享

### 4. 这个岗位/团队的真实情况
- 这是集团采购中心还是事业部采购？汇报给谁（采购总监 / 供应链总监 / 事业部总）？
- 团队规模？品类怎么分？是不是新立品类 / 新立项？
- 团队成功的标准是什么？年度降本目标大概怎么定？
- 上一个干这个岗位的人去哪了？为什么离开？（脉脉常有线索）
- 是否会出差 / 驻厂？是否背硬性 KPI（降本率 / OTD / 来料合格率）？

**建议源：**
- **领英 / 脉脉人脉** — 找已离职 / 在职的同岗位人，看履历变化
- **招聘平台的公司主页** — 看在招岗位结构，能反推团队规模与品类分工
- **脉脉同事圈** — 加入公司同事圈看内部讨论（需要邀请）

### 5. 薪酬与谈判情报
- 这个 title 在该公司大概对应采购序列哪一档（专员 / 高级专员 / 主管 / 经理）？
- 这个职级的薪资带宽？base × N + 年终奖结构？
- 年终奖通常多少个月？是否绑定降本 KPI？
- 有没有降本奖金 / 节约分成之类的机制？真实兑现情况？
- 这个公司在谈判时一般有多少 buffer？13薪 / 签字费是否常见？

**建议源：**
- **看准网薪酬频道（kanzhun.com/salary）** — 各级别真实薪酬
- **OfferShow（offershow.cn）** — 真实 offer 数据
- **脉脉职言** — 搜 "公司名 采购 薪资" / "公司名 跳槽涨幅"
- **职友集 / 猎聘** — 同城同职级带宽基线
- **知乎** — "X 公司 采购 薪资真实情况"

### 6. 竞品与差异化
- 主要竞品是哪些公司？
- 该公司的供应链优势是什么（成本 / 交期 / 质量 / 渠道）？
- 在 [我的品类方向] 上和竞品的差距？
- 行业内对它的整体评价（供应商口碑、付款信用、账期口碑）？

**建议源：**
- 行业报告（艾瑞 / 头豹 / 券商行研）
- 知乎行业讨论
- 脉脉行业圈 / 供应商社群

### 7. 候选人切入角度
鉴于我的背景（请读 cv.md 和 profile.yml 获取我的具体经历）：
- 我能给这个团队带去什么独特价值？
- 我哪段经历最该在面试时主讲（降本 / 供应商开发 / 交付保障）？
- 我应该讲什么故事？
- 哪些 gap 是我必须主动 address 的（品类不同 / 行业不同 / 资源不同）？
- 谈判时我有什么筹码？
```

---

## 使用方式

1. **填空**：把 `[公司]` 和 `[岗位]` 替换成实际信息，把 `[我的品类方向]` 改成候选人主攻品类
2. **跑 prompt**：可以分别跑在 Claude / Kimi / 通义 / 豆包上对比结果
3. **整合**：把 7 个维度的回答整合到 evaluation report 的 Block A 和 Block D
4. **特别注意 Section 3（工时）和 Section 5（薪酬）** — 这两个在国内是入职后悔率最高的两个维度，必须查清楚
