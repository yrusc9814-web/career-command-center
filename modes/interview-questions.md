# Mode: interview-questions — 采购面试题库（15 主题 × 4 职级）

> 供 `modes/offer.md` **Block F** 引用：按 JD 的 primary_archetype 与 seniority 档位选主题，按主题出题；答题素材走 Evidence-backed 规则。`modes/story-sync.md` 的 Story Bank 18 类与本题库主题一一呼应。

## 使用规则（先读）

1. **Evidence-backed（硬规则）**：给候选人准备答案素材时，**只允许使用 `candidate_evidence` / cv.md / article-digest.md 已有的事实**。CV 无对应案例 → 输出"**需要候选人补充真实案例**"，**禁止自动生成假 STAR、禁止编造数字与经历**。
2. **按职级选深度**：先按 JD seniority（助理 / 专员 / 高级专员 / 主管 / 经理 / 总监·负责人）确定问题档位，再选主题；跨档备选 1-2 题（JD 职级信号不足时用 unknown，不硬套）。
3. **按 JD 主题选重点**：JD 职责里高频出现的主题优先（寻源重 → Sourcing；降本重 → Cost Reduction）；每场面试准备 6-10 题，不要 15 主题全铺。
4. **答案结构 = STAR+R**：S/T/A/R + R（Reflection/Relevance — 这段经历对当前 JD 的价值）。数字口径来自 cv.md 真实事实，用候选人自己的数；没有数字就准备"口径 + 定性结果"，不编数。
5. **红线路径**：每题都要预判面试官的追问（"X% 怎么来的？""为什么选这家供应商？"），追问挂不住的数字不要主动说。

## 职级分层（4 档）

| 职级 | 题目侧重 |
|------|---------|
| **专员** | 执行真实性、流程、案例细节："你通常如何完成一次询价、核价到下单？" — 验证真的做过，听流程闭环 |
| **高级专员** | 专员档 + 独立供应商开发、复杂谈判、降本拆解、异常处理 — 验证独立承担，听方法与取舍 |
| **主管** | 高级专员档 + 供应风险、跨部门协调、年度目标拆解、供应商组合、带团队 — 验证从"自己干"到"带人背目标" |
| **经理 · 总监** | 主管档 + 品类策略、年度采购策略、组织管理、供应链韧性、预算、绩效机制、重大商务风险 — 验证体系与方法论 |

## 15 主题题库

### 1. Supplier Sourcing（供应商开发与寻源）

- **专员**：你是怎么找供应商的？用过哪些渠道（B2B 平台 / 展会 / 行业协会 / 转介绍）？拿到一家新供应商的资料后你先看什么？
- **高级专员**：讲一个你从 0 到 1 开发并导入的供应商：怎么筛选、验厂看什么、打样到批产分几步、卡在哪个环节？（素材：Story Bank「新供应商 0→1 开发」）
- **主管**：你负责的品类怎么定供应商开发计划？开发多少家、淘汰多少家怎么定？怎么平衡新导入风险和单一来源风险？
- **经理 · 总监**：供应商组合策略怎么定（核心 / 一般 / 备选分层）？怎么设计寻源团队的组织与分工？怎么衡量供应商开发的 ROI？

### 2. RFQ 比价（询比价与核价）

- **专员**：你通常如何完成一次询价、核价到下单？比价单上比哪几个维度（价格 / MOQ / Lead Time / 付款 / 模具费）？
- **高级专员**：两家报价差异超过 X%，你会怎么拆原因（材质 / 工艺 / 批量 / 管理成本）？讲一次你把报价拆到成本结构再谈下来的案例。
- **主管**：你所在小组的询比价规则是什么（几家起询 / 谁审批 / 什么情况免比价）？怎么防止比价流于形式？
- **经理 · 总监**：怎么建公司级的核价 / Should-cost 能力？比价数据沉淀怎么做（价格库 / 成本模型）？

### 3. Negotiation（商务谈判）

- **专员**：和供应商的日常议价你怎么做？你的让步空间谁给的？举一个你谈成的小案例。
- **高级专员**：讲一次最难的谈判：双方立场、你的准备（BATNA / 让步设计）、结果（价格 / 账期 / MOQ 组合）。（素材：Story Bank「降本谈判」）
- **主管**：年度框架谈判你怎么主导？谈崩了怎么办？怎么在价格、账期、交期、质量之间做组合让步？
- **经理 · 总监**：和战略供应商的高层谈判怎么准备？重大商务风险（违约 / 涨价函 / 断供威胁）怎么处理？谈判团队怎么分工授权？

### 4. Cost Reduction（降本与成本管理）

- **专员**：你执行过的降本动作有哪些（议价 / 替代料 / 包装 / 物流）？降本结果怎么统计口径？
- **高级专员**：讲一个降本项目：目标 X% 怎么拆到动作和品类？哪些动作贡献了几个点？（素材：Story Bank「降本谈判」）
- **主管**：年度降本目标怎么定、怎么分摊到品类和供应商？降本和质量的冲突怎么平衡？
- **经理 · 总监**：品类降本策略怎么设计（需求优化 / 规格标准化的权重）？降本绩效机制怎么设计才能不逼出质量事故？

### 5. Supplier Performance（供应商绩效与管理）

- **专员**：供应商的日常考核数据你怎么收集（OTD / 合格率 / 配合度）？月度评分表谁出？
- **高级专员**：一家长期低分但有替换成本的供应商你怎么处理？讲一次绩效面谈或整改推动的案例。
- **主管**：绩效考核维度和权重怎么定？淘汰机制怎么设计？怎么防止"评分高但配合差"的失真？
- **经理 · 总监**：供应商分级管理体系怎么搭？绩效结果怎么和份额分配 / 战略投入挂钩？

### 6. Delivery（交付与交期管理）

- **专员**：你怎么跟单和催交？交期异常的第一反应是什么？OTD 数据谁统计、怎么算？
- **高级专员**：讲一次紧急插单：产能不够、多方抢产能，你怎么协调排序和替代方案？（素材：Story Bank「紧急交付」）
- **主管**：交期保障机制怎么建（安全库存 / 瓶颈物料预警 / 供应商产能台账）？旺季怎么提前布局？
- **经理 · 总监**：交付体系怎么设计（预测 - 计划 - 执行的接口）？交期和库存的资金占用怎么平衡？

### 7. Quality（供应商质量与质量异常）

- **专员**：来料不合格你怎么处理（退换 / 挑选 / 让步接收）？谁判断、流程怎么走？
- **高级专员**：讲一次批量质量事故：怎么围堵、怎么让供应商整改、怎么赔偿？（素材：Story Bank「供应商质量事故」）
- **主管**：质量异常的分级和响应机制怎么定？SQE 和采购的边界怎么划分？
- **经理 · 总监**：供应商质量体系怎么前置（准入审核 / 过程审核）？质量成本怎么进供应商总成本？

### 8. Supply Interruption（供应中断与应急）

- **专员**：供应商突然断供你怎么办？第一时间报给谁、跟哪些部门联动？
- **高级专员**：讲一次供应中断（停产 / 火灾 / 物流中断）：你怎么找替代、保客户、控损失？（素材：Story Bank「供应中断」）
- **主管**：单一来源物料的预案怎么建（二供开发 / 库存缓冲 / 合同约束）？（素材：Story Bank「单一来源风险」）
- **经理 · 总监**：供应韧性的体系怎么建（多源布局 / 区域备份 / 关键物料战略储备）？中断复盘机制怎么落地？

### 9. Contract（合同与商务条款）

- **专员**：采购订单和合同你经手过哪些条款？价格条款和付款条款常见写法？
- **高级专员**：讲一次合同商务风险（账期违约 / 涨价条款 / 交付违约金）：你怎么发现和挽回？（素材：Story Bank「合同 / 商务风险」）
- **主管**：合同模板和审批流程你怎么把关？哪些条款是红线（质量责任 / 知识产权 / 违约金上限）？
- **经理 · 总监**：重大合同（长协 / 框架协议 / 联合开发）怎么审？商务条款怎么和供应策略配套？

### 10. Category Strategy（品类策略）

- **专员**：你负责 / 参与的品类是什么结构（供应商数量 / 集中度 / 价格波动性）？
- **高级专员**：给你的品类做过 Spend 分析或供应商矩阵吗？发现了什么、推动了什么改变？
- **主管**：一个品类的年度策略怎么写（供应市场分析 / 竞争格局 / 降本路径 / 风险）？
- **经理 · 总监**：品类管理体系的分层怎么设计（品类 Kraljic 矩阵 / 策略周期）？品类策略怎么和公司业务目标对齐？

### 11. Inventory（库存与物料计划协同）

- **专员**：库存高了你先查什么？呆滞预警谁出、多久出一次？
- **高级专员**：讲一次库存下降或呆滞处理：怎么拆原因（计划 / 批量 / 生命周期）、怎么消化？（素材：Story Bank「库存过高」「呆滞料」）
- **主管**：安全库存和 MOQ 策略怎么定？和计划 / 销售的库存责任怎么划分？
- **经理 · 总监**：库存周转指标怎么进采购考核？VMI / 寄售等模式什么品类适用？

### 12. Cross-functional Collaboration（跨部门协作）

- **专员**：研发指定供应商但价格高，你怎么处理？生产和采购抢交期怎么办？
- **高级专员**：讲一次跨部门冲突：销售 / 研发 / 生产的立场差异，你怎么推动达成方案？（素材：Story Bank「跨部门冲突」）
- **主管**：怎么建立采购和研发的早期介入（EPI）？跨部门的年度目标冲突怎么协调？
- **经理 · 总监**：采购在组织里的影响力怎么建（数据说话 / 流程接口 / 高层支持）？怎么让技术部门接受标准化降本？

### 13. ERP·SRM（数字化与流程）

- **专员**：你日常用的采购系统是什么（ERP / SRM / 报价平台）？下单到对账全流程走一遍。
- **高级专员**：讲一次你参与的流程线上化：原来手工怎么做、线上后效率变化（如关键单据流转从 X 小时到 Y 小时）？（素材：Story Bank「ERP·SRM 数字化采购」）
- **主管**：系统选型或模块上线你怎么参与需求定义？上线后怎么推供应商侧配合？
- **经理 · 总监**：数字化采购的路线图怎么定（主数据 / 流程 / 分析三层）？投入产出怎么评估？

### 14. International Procurement（国际采购与外贸）

- **专员**：进口 / 出口采购的单证流程你经手过哪些（报关 / 清关 / 信用证）？Incoterms 常用哪几个？
- **高级专员**：讲一次国际物流 / 外贸异常（清关卡关 / 海运延误 / 汇率波动）：你怎么处理？（素材：Story Bank「国际物流 / 外贸异常」）
- **主管**：国际供应商的寻源和验厂怎么做？关税 / 汇率 / 长运期的风险怎么进采购决策？
- **经理 · 总监**：全球采购布局怎么设计（区域平衡 / 关税规避 / 供应链转移）？国际采购团队怎么管理？

### 15. Management（团队与组织管理）

- **专员**：你带过新人或实习生吗？你怎么教他们走完第一个采购闭环？
- **高级专员**：你协调过临时小组或主导过专项吗？怎么分工和追进度？
- **主管**：你带几个人？小组的 KPI 怎么定和拆？新人怎么带、绩效怎么做？（素材：Story Bank「团队管理带新人」）
- **经理 · 总监**：采购组织的架构怎么设计（按品类 / 按职能）？岗位绩效机制怎么设计？怎么培养采购的职业通道？

## 与其他 mode 的关系

- `modes/offer.md` Block F：按本题库选主题出题，故事素材来自 candidate_evidence，输出 STAR+R 表。
- `modes/story-sync.md`：Block F 产出的故事沉淀进 Story Bank（18 类），mock 面试后回流 refinement。
- 职级档位判定：权威实现 = `tools/lib/taxonomy.mjs`（`normalizeSeniority`）；本题库只按"专员 / 高级专员 / 主管 / 经理·总监"四档组织内容，JD 职级 unknown 时四档全部给出并标注"需面试确认"。
